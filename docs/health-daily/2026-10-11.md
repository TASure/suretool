## 诊断明细

**CI Windows 失败（run 38118482186，job 114408127163）**
- 失败点：`sure-core` → `SettingUtilTest.环境变量优先于文件()`（第 85 行）
- 报错：`org.junit.ComparisonFailure: expected:<[C:\Users\runneradmin]> but was:<[file_value]>`
- 根因：`SettingUtil.resolve()` 环境变量查找仅用 `System.getenv(envName(key))`（点转下划线大写），`home` → `HOME`；Windows runner 无 `HOME` 环境变量（仅有 `USERPROFILE`），取值 null → 回落到配置文件值 `file_value`。Linux/macOS 有 `HOME` 故通过。
- 影响：Windows 用户配置 `key=home` 时取不到主目录（跨平台缺陷，非本次 CI 引入）。
- 修复计划：① `SettingUtil` 在映射名为 `HOME` 且取值为 null 时回退 `USERPROFILE`（治本）；② 测试按平台断言（治标）；③ 本地 `mvn -pl sure-core verify`（0.98 覆盖率门禁）通过后 push。
