## 自动处理明细（批50）

1. **WatchDir.loop 周期快照无条件化**：快照兜底从 `poll==null` 分支移出，每 1s 无条件执行——修复 Windows 事件密集时快照被饿死（4×15s 超时的根因）。
2. **WatchDir.backfill 单条目容错**：DirectoryStream 迭代内逐项 try-catch（RuntimeException），单条目句柄占用不中断整体枚举——修复溢出补发 CREATE 缺失（0.006s 断言失败根因）。
3. **FileTailer TOCTOU 修复**：`exists`+`readAttributes` 合并为原子读，`NoSuchFileException` 按 vanished 处理——修复 Windows rename+新建间隙轮转检测中断（L246 超时根因）。
